# Live Polling App

A real-time live polling application that allows users to create polls and vote on available options.

## Features

- Create polls with multiple options
- Vote on poll options
- View updated vote counts
- Persistent poll and vote data
- React-based frontend
- Go and Gin-based backend
- MongoDB database
- Redis integration for real-time communication

## Technologies Used

### Frontend
- React
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Go
- Gin Framework
- MongoDB
- Redis
